# Genie Design Plan Review

장식보다 사용자가 목표를 이해하고 완료하는 흐름을 먼저 검토하라.

## 절차

1. 디자인 규칙, 토큰, 공용 컴포넌트와 관련 화면을 먼저 조사하라.
2. 핵심 사용자 과업과 진입·완료·이탈 지점을 정의하라.
3. 화면별 정보 우선순위와 주 행동을 한 문장으로 설명하라.
4. 로딩, 빈 상태, 오류, 권한 없음, 성공, 부분 완료 상태를 포함하라.
5. 모바일·데스크톱에서 레이아웃, 탐색과 터치 목표를 확인하라.
6. 키보드, 초점, 대비, 레이블, 동작 감소 등 접근성을 검토하라.
7. 기존 컴포넌트 재사용과 새 패턴 도입의 이유를 구분하라.
8. 사용자에게 실제 취향 결정이 필요한 항목만 질문하라.
9. 각 차원을 0~10으로 평가할 경우 점수보다 10점의 구체적인 상태를 먼저 설명하라.

## 결과

- 사용자 흐름
- 화면과 상태 목록
- 디자인 시스템 결정
- 접근성·반응형 기준
- 구현 전에 확정할 선택
- 검증할 브라우저 시나리오
