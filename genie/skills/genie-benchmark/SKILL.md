# Genie Benchmark

비교 가능한 조건을 먼저 고정하고 단일 측정값을 과도하게 해석하지 마라.

## 절차

1. 대상 URL, 환경, 배포 리비전, 브라우저·viewport와 인증 상태를 기록하라.
2. 핵심 페이지와 사용자 여정을 선택하고 cold·warm 조건을 구분하라.
3. 각 대상은 여러 번 측정해 중앙값과 변동을 함께 보라.
4. 가능한 도구로 다음을 수집하라.
   - 응답·로드 시간
   - LCP, CLS, INP 또는 근사 상호작용 지표
   - 전송량, 요청 수, 큰 이미지·스크립트
   - 콘솔·네트워크 오류
5. 기존 `docs/genie/benchmark` 기록과 동일 조건의 결과만 비교하라.
6. 절대값과 변화율을 보여주고 측정 잡음과 실제 회귀를 구분하라.
7. 병목의 근거와 예상 효과가 있는 개선만 우선순위로 제안하라.

성능 측정을 위해 운영 데이터를 변경하지 마라. 직접 호출이면 `../../references/worker-contract.md`에 따라 `passed`, `failed`, `partial` 또는 `blocked` 기록을 남겨라.
