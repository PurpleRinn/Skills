# Genie Investigate

근본 원인을 확인하기 전에는 해결책을 확정하지 마라.

## 절차

1. 기대 동작, 실제 동작, 최초 발생 시점과 재현 조건을 분리하라.
2. 로그, 오류, 입력, 환경, 최근 변경과 관련 코드를 수집하라.
3. 문제의 데이터 흐름을 입력부터 실패 지점까지 추적하라.
4. 관찰과 추측을 구분해 가능한 원인 가설을 우선순위로 세워라.
5. 각 가설을 반증할 수 있는 가장 작은 검사를 수행하라.
6. 확인된 원인이 동일 패턴으로 다른 위치에도 존재하는지 검색하라.
7. 사용자가 진단만 요청했다면 원인과 근거까지만 보고하라.
8. 수정까지 요청했다면 최소 수정 후 관련 테스트와 원래 재현 절차로 검증하라.
9. 같은 접근의 수정이 세 번 실패하면 중단하고 가정과 범위를 재검토하라.

## 결과

- 재현 조건
- 근본 원인과 증거
- 기각한 가설
- 영향 범위
- 수정 내용 또는 권장 수정
- 회귀 방지 검증
