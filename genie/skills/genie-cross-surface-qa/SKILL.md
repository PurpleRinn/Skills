# Genie Cross Surface QA

한 영역의 성공만으로 완료 처리하지 말고 사용자 행동이 모든 관련 영역에서 일관되게 이어지는지 확인하라.

## 절차

1. `.genie/config.json`의 `detected.surfaces`, `frameworks`, `paths`와 `capabilities`를 읽고 관련 영역을 정하라.
2. 모바일이 포함되면 해당 모바일 어댑터, 웹이 포함되면 `../../references/web-frameworks.md`를 읽어라.
3. 하나의 추적 가능한 테스트 데이터를 만들고 다음 흐름을 검증하라: 생성·변경 주체 → API·이벤트·DB → 소비 화면 → 캐시·동기화 → 권한별 표시.
4. 관리자 변경의 모바일 반영, 모바일 입력의 관리자 표시, 삭제·비활성화, 로그아웃·토큰 만료, 중복 요청과 재시도를 확인하라.
5. 실시간·푸시·오프라인 기능이 있으면 지연, 순서 역전, 재연결과 중복 전달을 확인하라.
6. 실패 지점이 어느 영역의 계약 위반인지 분리하고 관련 경로와 재현 증거를 남겨라.

사용자가 수정을 요청하지 않으면 코드를 변경하지 마라. 직접 호출이면 `../../references/worker-contract.md`에 따라 `docs/genie/cross-surface-qa`에 기록하라.
