# Genie QA

브라우저에서 확인한 문제만 수정하고 수정 후 같은 경로를 다시 검증하라.

## 절차

1. 대상 URL, 환경, 커밋·배포 리비전, 인증과 외부 영향 범위를 확인하라.
2. 핵심 사용자 여정과 실패·경계 입력을 브라우저에서 실행하라.
3. 문제마다 재현 단계, 기대·실제 결과와 증거를 기록하라.
4. 관련 코드를 찾아 근본 원인을 확인하라. 증상만 가리는 수정은 피하라.
5. 요청 범위 안에서 가장 작은 완전한 수정을 적용하라.
6. 가능한 경우 같은 실패를 재현하는 자동 회귀 테스트를 추가하라.
7. 관련 테스트, 타입체크와 빌드를 실행하라.
8. 원래 브라우저 재현 절차를 다시 실행하고 콘솔·네트워크까지 확인하라.
9. 수정이 새로운 문제를 만들면 자체 반복하되 같은 접근이 세 번 실패하면 중단하라.

결제, 삭제, 실제 메시지 전송, 운영 데이터 변경은 명시적 허용 없이 수행하지 마라. 직접 호출이면 `../../references/worker-contract.md`에 따라 `passed`, `failed`, `partial` 또는 `blocked` 기록을 남겨라.
