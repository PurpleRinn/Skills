# Genie Mobile QA

수정 권한이 명확한 요청에서만 사용하라. 재현되지 않은 문제를 추측으로 고치지 마라.

## 절차

1. `.genie/config.json`에 따라 Flutter이면 `../../references/flutter-mobile.md`, React Native 또는 Expo이면 `../../references/react-native-mobile.md`를 읽고 대상 플랫폼과 기능 특성을 확인하라.
2. 변경 전 기기·빌드·앱 버전·계정 상태와 최소 재현 절차를 고정하라.
3. 로그, 네트워크, 상태 전파와 네이티브 경계를 따라 근본 원인을 확인하라. 세 번 연속 실패하면 접근을 재평가하라.
4. 가장 작은 수정과 재현 시나리오를 포착하는 자동 회귀 테스트를 추가하라.
5. 정적 분석과 관련 테스트를 실행하고 앱을 다시 빌드·설치한 뒤 같은 기기 상태에서 재검증하라.
6. Android와 iOS 공용 코드 변경이면 영향 가능한 두 플랫폼을 확인하거나 검증하지 못한 플랫폼을 명시하라.
7. 수정과 무관한 버전 상승, 서명, 스토어 제출이나 운영 배포는 수행하지 마라.

직접 호출이면 `../../references/worker-contract.md`에 따라 `docs/genie/mobile-qa`에 기록하라.
